## What it does

`main.ts` writes exactly two lines to `/output/entry.txt`:

1. A warning to my past self about one specific moment — a rainy Tuesday in October 2018, when my mother called to say Dad was in the hospital.
2. One sentence on why that moment mattered and what changed because of it.

The entry is 226 characters, exactly two lines, within the 1–280 character gate.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18+ (TypeScript runs as-is). No dependencies, no network, no secrets.
